Qué problema resuelve NoteFlow para el usuario:
    NoteFlow nace para evitar el caos de usar mil apps distintas para cosas simples como anotar ideas, hacer listas o guardar notas importantes. En lugar de saltar entre aplicaciones, todo queda unificado en un solo lugar, lo que reduce distracciones y mejora el enfoque.

Quién es el usuario objetivo y cómo usaría la app en su día a día:
    Está pensado para estudiantes y jóvenes profesionales que necesitan una herramienta diaria para:
     - Apuntar ideas.
     - Organizar tareas con checklists.
     - Guardar notas más completas para estudiar o trabajar.

Lista de funcionalidades principales para esta primera versión:
    - Crear, ver y borrar notas de texto.
    - Hacer listas con porcentaje de progreso.
    - Guardar ideas rápidas con etiquetas y colores.
    - Guardar todo localmente para no perder nada al cerrar la app.

Lista de funcionalidades opcionales que podrían añadirse más adelante.
    - Sincronización en la nube.
    - Recordatorios con notificaciones.
    - Búsqueda avanzada y filtros por etiquetas.
    - Archivar elementos en vez de eliminarlos.
